Create a modern Hospital Management System web application UI with a clean, professional healthcare design theme. The interface should be responsive, user-friendly, and suitable for hospital staff and patients.

Include the following UI pages/modules:

1. **Admin Dashboard**

   * Overview statistics (patients, doctors, appointments, revenue)
   * User management
   * Reports and analytics
   * Navigation sidebar

2. **Doctor Panel**

   * View daily appointments
   * Live waiting list dashboard showing queued patients
   * Patient records access
   * Prescription management
   * Consultation status controls (waiting / in-progress / completed)
   * Real-time refresh of waiting list
   * Daily schedule overview

3. **Reception Panel**

   * Patient registration form
   * Appointment booking
   * Add patients to doctor waiting queue
   * Billing preview
   * Check-in/check-out interface

4. **Patient Portal**

   * Profile management
   * Appointment history
   * Prescription view
   * Medical records
   * Doctor availability display (Available / Busy / Offline)
   * Estimated waiting time based on queue
   * Option to join waiting list

5. **About Us Page**

   * Hospital introduction
   * Mission & vision
   * Doctor highlights
   * Facility showcase

6. **Contact Us Page**

   * Contact form
   * Hospital address & phone
   * Map section
   * Emergency contact display

7. **Landing/Home Page**

   * Hero section
   * Services overview
   * Doctor cards with live availability badges
   * Call-to-action buttons

Functional requirements:

* Doctors see a real-time waiting list with patient names, arrival time, and status
* Reception can manage queue entries
* Patients can see live doctor availability
* Status indicators for priority/emergency
* Dynamic dashboard updates

Design requirements:

* Medical color palette (blue/white/green)
* Clean cards and dashboard widgets
* Icons for navigation
* Modern typography
* Responsive layout for desktop and mobile
* Smooth transitions and hover effects

Generate UI structure, layout ideas, component descriptions, and functional behavior for each page.
